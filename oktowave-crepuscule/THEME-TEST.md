# OktoWave — Crépuscule theme (web test version)

A **test copy of the OktoWave web app** (Okto MultiWave Synth 1.0.5 + the web update of 2026-10-21) with the **Crépuscule** look: orange-to-violet frosted glass, gold accent for the subtractive
oscillators A1 A2, cyan for the additive B1, one flat outline for the oscillator tab and its plate, and the **preset browser** in the same style (its own glass panel at the right of the synth).

- Open it: https://pierrearnaudguyot.github.io/Wavelet-Synthesizer-TEST/oktowave-crepuscule/ (Edge or Chrome, a MIDI keyboard plays it directly; ▶ DEMO runs the tour).
- Nothing else of this repository changes: the Wavelet Synthesizer test and its voting session stay at the root of the site (`web/`).
- The official OktoWave web app (current look, no theme): https://pierrearnaudguyot.github.io/Free-Wavelet-Synthesizer-VST/web/
- What changed against it: `css/synth.css` (the whole look, as variables and rules), `js/ui.js` (the accent colours `#ffd166` / `#7ae7ff`, the outline drawn flat). The manual pages still show the old look.
- Web only: the plug-in is not themed (it has no backdrop blur; a second step if the look is kept).
